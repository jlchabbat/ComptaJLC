ComptaBB – Installation et mises à jour

Le site · https://comptabb.pythonanywhere.com · 27/09/2026

1. Une application en ligne

ComptaBB est un site hébergé chez PythonAnywhere : on s'y connecte de partout (ordinateur, tablette, téléphone), par internet, avec une connexion chiffrée. Il n'y a rien à installer sur les ordinateurs. Les données sont dans comptabb-data sur PythonAnywhere, sauvegardées automatiquement chaque nuit et à chaque mise à jour ; les exports se téléchargent depuis l'application. (L'ancien programme Windows, ComptaBB.exe, est abandonné.)

2. Les rôles et les mots de passe

RôleDroits
AdministrateurTous les droits, dont le paramétrage de base, les utilisateurs et la base de données
TrésorierLa tenue quotidienne : saisie, tiers, consultation, banque, contrôles, éditions (ni paramétrage, ni imports / exports, ni base de données)
BureauConsultation seulement
BénévoleLa liaison seulement : ses fiches bénévoles

Créer un compte

  • Trésorier ou bureau : Administration › Utilisateurs, carte « Nouvel utilisateur » : identifiant (un nom ou une adresse e-mail), prénom, nom, e-mail, rôle, mot de passe provisoire ; Créer l'utilisateur en haut à gauche.
  • Bénévole : Saisie › Fiches bénévoles, carte « Nouveau bénévole » : choisir le membre (le bénévole est toujours un membre), identifiant et mot de passe ; Créer le bénévole en haut.

Changer un mot de passe

  1. Par l'administrateur, pour quelqu'un d'autre : Administration › Utilisateurs, clic sur l'identifiant de la personne, taper le mot de passe dans « Nouveau mot de passe » (vide = inchangé), Enregistrer en haut à gauche, puis le transmettre. La même page permet de changer l'identifiant, l'e-mail, le rôle, ou de bloquer l'accès (décocher « Peut se connecter »).
  2. Par chacun, pour lui-même : clic sur son nom en haut à droite (Mon compte), ancien mot de passe puis le nouveau deux fois, Changer le mot de passe en haut à gauche. On y change aussi son identifiant et son e-mail ; on peut se connecter avec l'un ou l'autre.

Conseil : l'administrateur donne un mot de passe provisoire, chacun le remplace par le sien. Un mot de passe compte au moins 8 caractères, pas uniquement des chiffres, ne ressemble pas à l'identifiant et n'est pas trop courant ; en cas de refus, le motif s'affiche sous la case.

3. Mettre à jour le site (PythonAnywhere)

1. Télécharger le code sur GitHub

  1. Ouvrir la page du code de la branche à installer, par exemple github.com/jlchabbat/ComptaBB/tree/claude/keen-tesla-q5sib5. Le sélecteur de branche, au-dessus de la liste des fichiers, doit afficher le nom de la branche.
  2. Bouton vert <> Code (à droite de « Add file ») › Download ZIP.
  3. Le fichier s'appelle ComptaBB-<nom de la branche>.zip, par exemple ComptaBB-claude-keen-tesla-q5sib5.zip.
Toujours prendre la branche indiquée : les branches ne se cumulent pas entre elles. Dans une même branche, le dernier envoi contient tous les précédents.

2. L'envoyer sur PythonAnywhere

Onglet Files, dossier /home/ComptaBB/, Upload a file.

3. Installer, dans une console Bash

Onglet Consoles › Bash. Taper les commandes au clavier plutôt que les coller (un collage peut ajouter le texte de la ligne précédente) ; le tilde ~ s'obtient avec AltGr + 2 puis Espace, ou écrire /home/ComptaBB/ à sa place.

ls ~/*.zip

Le nom doit commencer par ComptaBB-. Sinon, le renommer : mv ~/"NOM AFFICHÉ.zip" ~/ComptaBB-maj.zip. Pour vérifier la version : unzip -l ~/ComptaBB-….zip | head -5 doit montrer un dossier ComptaBB-<branche>/.

bash ~/maj.sh

Le script affiche 5 étapes : sauvegarde de la base, nouveau code, bibliothèques, base de données et paramètres, rechargement du site ; puis « MISE À JOUR TERMINÉE ». L'ancien code est gardé dans ComptaBB-ancien, le ZIP est supprimé.

4. Vérifier

Ouvrir le site et appuyer sur Ctrl+F5. En cas de problème, remettre la version précédente du code :

bash ~/maj.sh --retour

Les données (comptabb-data) ne sont jamais touchées par une mise à jour. La présentation et le mode d'emploi du menu Éditions sont mis à jour en même temps.

Les coches de GitHub

Dans l'onglet Actions, chaque envoi est vérifié (tests automatiques). Une coche verte : tout est passé ; une croix rouge : un contrôle a échoué, à signaler avant d'installer. Une vérification n'ajoute ni n'enlève rien au code.

4. Sauvegarder et restaurer

Par l'application

  • Administration › Base de données : Créer une sauvegarde, Télécharger la base maintenant, Tout exporter (export complet .zip), Remettre à zéro et recharger depuis une sauvegarde, un export complet ou le classeur (taper REMPLACER).
  • Administration › Imports / Exports : Tout exporter et sauvegarder la base (un fichier par nature de données, Parametres.xlsx et une copie de la base).
  • Éditions › Exports (référentiels, écritures) : un fichier Excel par référentiel, les écritures, relevés et budget ; « Tout exporter » en .zip.

Par la console (site)

Se placer d'abord dans l'application :

cd ~/ComptaBB/appli && source ~/venv/bin/activate && export COMPTABB_DATA=~/comptabb-data
CommandeEffet
python manage.py sauvegarderSauvegarde de la base (les 3 dernières sont gardées).
python manage.py restaurerListe les sauvegardes, les plus récentes d'abord.
python manage.py restaurer 3
python manage.py restaurer derniere		Remet la base dans l'état de la sauvegarde n° 3 (ou de la plus récente), après confirmation REMPLACER ; l'état actuel est sauvegardé juste avant.
python manage.py exporter_toutJeu complet d'exports et sauvegarde de la base.
python manage.py changepassword identifiantNouveau mot de passe pour un utilisateur (secours).
python manage.py creer_administrateurCrée un compte administrateur (secours).

Sauvegarde automatique chaque nuit (site)

PythonAnywhere, onglet Tasks, tâche quotidienne avec la commande :

COMPTABB_DATA=/home/ComptaBB/comptabb-data /home/ComptaBB/venv/bin/python /home/ComptaBB/ComptaBB/appli/manage.py sauvegarder

5. Réglages de l'association

Chaque association a son propre site ; ce qui lui est propre se règle dans Administration › Paramètres (Excel) (fichier Parametres.xlsx : exporter, modifier la colonne Valeur, réimporter). Une valeur vide désactive l'option.

CléValeur de la LogeEffet
nom_associationLoge Bnei BrithNom affiché en haut des pages, sur la situation financière et les éditions.
devise₪Symbole des montants (écrans, Excel, messages). Nouvelle association : €.
releves_mizrahiB1,B2Journaux dont le relevé PDF est au format Mizrahi-Tefahot (hébreu). Vide : relevés en Excel, CSV ou PDF en tableau.
releve_bitB3Journal du relevé Bit (format imposé, remplace le précédent). Vide : pas de Bit (ni moyen de paiement BIT).
carte_bancaireIsracardCarte réglée par la banque le mois suivant (modèle « Paiement carte … », mode « Carte … » des fiches). Vide : pas de carte.
hebergeur_liensSUMITSite qui héberge des justificatifs gardés en lien (cadre « Joindre un lien » d'un mouvement). Vide : pas de lien.
traductions_releveouiTraduction hébreu → français des libellés du relevé (menu Banque › Traductions). Non : libellés tels quels.

Les moyens de paiement, modèles de saisie et modes des fiches déjà créés ne changent pas quand on modifie un réglage : ils se corrigent dans Administration › Référentiels.

6. Installer le site d'une nouvelle association

Chaque association a son propre site, avec le même programme que celui de la Loge et ses propres données. Compter une demi-heure.

A. Le compte et l'application web (PythonAnywhere)

  1. Sur www.pythonanywhere.com : Pricing & signup › Create a Beginner account (gratuit pour essayer ; environ 5 $ par mois ensuite). L'identifiant choisi donne l'adresse du site : amisdumusee → amisdumusee.pythonanywhere.com. Confirmer l'adresse e-mail.
  2. Onglet Web › Add a new web app › Next › Manual configuration › Python 3.12 › Next.

B. Le programme

  1. Sur GitHub, dépôt ComptaBB, la branche en service › Code › Download ZIP.
  2. PythonAnywhere, onglet Files › Upload a file : envoyer le ZIP (sans le renommer ni l'ouvrir).
  3. Onglet Consoles › Bash, puis copier cette ligne et appuyer sur Entrée :
unzip -qo ComptaBB-*.zip -d ~/inst && bash ~/inst/*/appli/deploiement/installer.sh

Le script installe le programme et ses bibliothèques (quelques minutes), crée la base vide, écrit le fichier WSGI du site et le script de mise à jour ~/maj.sh. Il termine par INSTALLATION TERMINÉE et un code d'installation de 8 caractères : le noter.

C. Les réglages de l'application web

Onglet Web, sur la page de l'application :

RubriqueValeur (remplacer NOM par l'identifiant)
Virtualenv/home/NOM/venv
Static filesURL /static/, dossier /home/NOM/comptabb-data/static
Force HTTPSEnabled

Puis le bouton vert Reload.

D. Le premier démarrage (dans le navigateur)

  1. Ouvrir https://NOM.pythonanywhere.com : la page « Bienvenue dans ComptaBB » demande le code d'installation, puis l'identifiant et le mot de passe (12 caractères au moins) de l'administrateur.
  2. La page « Premier démarrage » décrit l'association : nom, devise, plan comptable (plan de base proposé, ou vos propres fichiers à partir des modèles vierges), premier exercice, jusqu'à trois banques avec le format de leur relevé, caisse, options. « Démarrer ComptaBB » crée tout d'un coup ; tout reste modifiable ensuite (chapitre 5).
  3. Créer les utilisateurs (Administration › Utilisateurs) et importer les membres (modèle vierge Tiers).
  4. Sauvegarde automatique de chaque nuit : chapitre 4 (onglet Tasks), avec l'identifiant de l'association.

Pour une réinstallation (nouveau compte, données existantes) : après l'étape D.1, « Recharger une sauvegarde » (Administration › Base de données) remplace l'assistant. Un site qui a déjà des journaux ou des écritures ne voit jamais l'assistant.

E. Les mises à jour

Comme pour la Loge (chapitre 3) : envoyer le nouveau ZIP dans Files, puis bash ~/maj.sh. Les données de l'association ne sont jamais touchées. Tous les 3 mois avec l'offre gratuite : onglet Web › Run until 3 months from today.

F. La licence

Un site créé par l'assistant a 60 jours d'essai. Ensuite, sans licence valable, il passe en lecture seule : on consulte, on imprime et on exporte (export complet compris), on ne saisit plus. Le site de la Loge, installé avant l'assistant, n'est jamais concerné.

Côté éditeur (sur votre propre compte, console du site) :

CommandeEffet
python manage.py licence clesUne seule fois : crée la clé privée dans ~/comptabb-licence (à garder secrète et à sauvegarder hors du site) et affiche la clé publique, à inscrire dans le programme (compta/licence.py, CLE_PUBLIQUE). Tant qu'elle n'y est pas, aucune licence n'est demandée.
python manage.py licence creer --association "Amis du musée" --site amisdumusee.pythonanywhere.com --fin 2027-12-31Affiche la licence (texte CBB1.…) à envoyer à l'association.
python manage.py licence verifier "CBB1.…"Affiche l'association, le site et la date de fin d'une licence.

Côté association : Administration › Licence, coller le texte reçu, « Enregistrer la licence ».
