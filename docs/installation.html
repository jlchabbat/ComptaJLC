ComptaBB – Installation et mises à jour

Le site et le programme du PC · https://comptabb.pythonanywhere.com · 27/09/2026

1. Une seule application, deux façons de l'utiliser

Le site et le programme du PC sont la même application : même code, mêmes menus, mêmes fonctionnalités. Chaque mise à jour vaut pour les deux. Ce qui change, c'est où elle tourne, qui peut s'y connecter et où sont les données.

Site (PythonAnywhere)PC (ComptaBB.exe)
AccèsDe partout (ordinateur, tablette, téléphone), par internet, connexion chiffréeSeulement sur ce PC, tant que la fenêtre noire est ouverte
UtilisateursAdministrateur, trésorier, bureau, bénévoles, chacun de chez soiEn pratique une seule personne, devant ce PC
Donnéescomptabb-data sur PythonAnywhereappli\data sur le PC ; copie de celle du site en un clic (« Recevoir la base du site »)

Recommandation. Le site est l'outil principal : c'est le seul qui permet au bureau et aux bénévoles d'y accéder, donc à la liaison de fonctionner. Le PC est un outil d'appoint (travail hors connexion, vérifications, exports directement dans OneDrive) : avant de l'utiliser, y recharger la base du site, et ne rien y saisir, sinon les deux bases divergent.

2. Les rôles et les mots de passe

RôleDroits
AdministrateurTous les droits, dont le paramétrage de base, les utilisateurs et la base de données
TrésorierTout, sauf le paramétrage de base
BureauConsultation seulement
BénévoleLa liaison seulement : ses fiches bénévoles

Créer un compte

  • Trésorier ou bureau : Administration › Utilisateurs, carte « Nouvel utilisateur » : identifiant (un nom ou une adresse e-mail), prénom, nom, e-mail, rôle, mot de passe provisoire ; Créer l'utilisateur en haut à gauche.
  • Bénévole : Saisie › Fiches bénévoles, carte « Nouveau bénévole » : choisir le membre (le bénévole est toujours un membre), identifiant et mot de passe ; Créer le bénévole en haut.

Changer un mot de passe

  1. Par l'administrateur, pour quelqu'un d'autre : Administration › Utilisateurs, clic sur l'identifiant de la personne, taper le mot de passe dans « Nouveau mot de passe » (vide = inchangé), Enregistrer en haut à gauche, puis le transmettre. La même page permet de changer l'identifiant, l'e-mail, le rôle, ou de bloquer l'accès (décocher « Peut se connecter »).
  2. Par chacun, pour lui-même : clic sur son nom en haut à droite (Mon compte), ancien mot de passe puis le nouveau deux fois, Changer le mot de passe en haut à gauche. On y change aussi son identifiant et son e-mail ; on peut se connecter avec l'un ou l'autre.

Conseil : l'administrateur donne un mot de passe provisoire, chacun le remplace par le sien. Un mot de passe compte au moins 8 caractères, pas uniquement des chiffres, ne ressemble pas à l'identifiant et n'est pas trop courant ; en cas de refus, le motif s'affiche sous la case.

3. Mettre à jour le site (PythonAnywhere)

1. Télécharger le code sur GitHub

  1. Ouvrir la page du code de la branche à installer, par exemple github.com/jlchabbat/ComptaBB/tree/claude/keen-tesla-q5sib5. Le sélecteur de branche, au-dessus de la liste des fichiers, doit afficher le nom de la branche.
  2. Bouton vert <> Code (à droite de « Add file ») › Download ZIP.
  3. Le fichier s'appelle ComptaBB-<nom de la branche>.zip, par exemple ComptaBB-claude-keen-tesla-q5sib5.zip.
Pas l'onglet Actions. Le fichier ComptaBB.zip de l'onglet Actions (Artifacts) est le programme Windows du PC (il contient ComptaBB.exe) : il ne fonctionne pas sur le site. Les branches ne se cumulent pas entre elles : toujours prendre la branche indiquée. Dans une même branche, en revanche, le dernier envoi contient tous les précédents.

2. L'envoyer sur PythonAnywhere

Onglet Files, dossier /home/ComptaBB/, Upload a file.

3. Installer, dans une console Bash

Onglet Consoles › Bash. Taper les commandes au clavier plutôt que les coller (un collage peut ajouter le texte de la ligne précédente) ; le tilde ~ s'obtient avec AltGr + 2 puis Espace, ou écrire /home/ComptaBB/ à sa place.

ls ~/*.zip

Le nom doit commencer par ComptaBB-. Sinon, le renommer : mv ~/"NOM AFFICHÉ.zip" ~/ComptaBB-maj.zip. Pour vérifier la version : unzip -l ~/ComptaBB-….zip | head -5 doit montrer un dossier ComptaBB-<branche>/.

bash ~/maj.sh

Le script affiche 5 étapes : sauvegarde de la base, nouveau code, bibliothèques, base de données et paramètres, rechargement du site ; puis « MISE À JOUR TERMINÉE ». L'ancien code est gardé dans ComptaBB-ancien, le ZIP est supprimé.

4. Vérifier

Ouvrir le site et appuyer sur Ctrl+F5. En cas de problème, remettre la version précédente du code :

bash ~/maj.sh --retour

Les données (comptabb-data) ne sont jamais touchées par une mise à jour. La présentation et le mode d'emploi du menu Éditions sont mis à jour en même temps.

Les coches de GitHub

Dans l'onglet Actions, chaque envoi est vérifié (tests automatiques, puis construction de ComptaBB.exe). Une coche verte : tout est passé ; une croix rouge : un contrôle a échoué, à signaler avant d'installer. Une vérification n'ajoute ni n'enlève rien au code.

4. Installer le programme sur le PC

1. Récupérer le programme

  1. Ouvrir github.com/jlchabbat/ComptaBB/actions.
  2. Cliquer sur la ligne la plus récente de la branche, avec une coche verte.
  3. Tout en bas, Artifacts › ComptaBB : le fichier ComptaBB.zip se télécharge.

2. L'installer

  1. Clic droit sur ComptaBB.zip › Extraire tout… vers D:\OneDrive\Applications\ComptaBB\appli (on y trouve ComptaBB.exe et un dossier _internal).
  2. Clic droit sur ComptaBB.exe › Afficher plus d'options › Envoyer vers › Bureau (créer un raccourci).

3. Premier lancement

  1. Double-clic sur ComptaBB.exe. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires › Exécuter quand même (le programme n'est pas signé).
  2. La fenêtre noire demande l'identifiant et le mot de passe de l'administrateur (8 caractères au moins, à retaper), puis le classeur ComptaBB.xlsm à reprendre (chemin complet, ou Entrée pour une base vide).
  3. Le navigateur s'ouvre sur http://127.0.0.1:8765 : se connecter.

4. Utilisation

  • Double-clic sur l'icône du Bureau. Laisser la fenêtre noire ouverte : la fermer arrête ComptaBB.
  • Exports et sauvegardes : D:\OneDrive\Applications\ComptaBB\Exports et …\Exports\Sauvegardes (réglables dans Administration › Imports / Exports).
  • Données : D:\OneDrive\Applications\ComptaBB\appli\data\comptabb.sqlite3.
  • Mettre à jour : télécharger le nouveau ComptaBB.zip (Actions) et l'extraire au même endroit en remplaçant les fichiers ; le dossier data est conservé.

5. Avoir sur le PC les données du site : « Recevoir la base du site »

  1. Sur le PC, dans ComptaBB : Administration › Base de données, carte Recevoir la base du site (elle n'existe que sur le PC).
  2. Adresse du site (proposée : https://comptabb.pythonanywhere.com), identifiant et mot de passe d'un administrateur du site (ils ne sont pas enregistrés), taper REMPLACER.
  3. Bouton Recevoir la base du site, en haut à gauche : le PC télécharge la base du site, la vérifie et remplace la sienne ; la base précédente du PC est sauvegardée juste avant.
  4. Se reconnecter avec ses identifiants du site : les utilisateurs du PC sont désormais ceux du site.

Sens unique, du site vers le PC : à refaire chaque fois qu'on veut une copie à jour. Sans internet, la méthode manuelle reste possible : sur le site, Télécharger la base maintenant ; sur le PC, Remettre à zéro et recharger avec ce fichier.

Deux bases distinctes. Ce qui est saisi sur l'un n'apparaît pas sur l'autre : ne saisir qu'à un seul endroit (le site). OneDrive : fermer ComptaBB avant d'éteindre le PC ou de laisser OneDrive synchroniser, car une base ouverte peut être mal copiée. Les sauvegardes de Exports\Sauvegardes restent la copie de sécurité.

5. Sauvegarder et restaurer

Par l'application

  • Administration › Base de données : Créer une sauvegarde, Télécharger la base maintenant, Tout exporter (export complet .zip), Remettre à zéro et recharger depuis une sauvegarde, un export complet ou le classeur (taper REMPLACER).
  • Administration › Imports / Exports : Tout exporter et sauvegarder la base (un fichier par nature de données, Parametres.xlsx et une copie de la base).
  • Éditions › Exports (référentiels, écritures) : un fichier Excel par référentiel, les écritures, relevés et budget ; « Tout exporter » en .zip.

Par la console (site)

Se placer d'abord dans l'application :

cd ~/ComptaBB/appli && source ~/venv/bin/activate && export COMPTABB_DATA=~/comptabb-data
CommandeEffet
python manage.py sauvegarderSauvegarde de la base (les 30 dernières sont gardées).
python manage.py restaurerListe les sauvegardes, les plus récentes d'abord.
python manage.py restaurer 3
python manage.py restaurer derniere		Remet la base dans l'état de la sauvegarde n° 3 (ou de la plus récente), après confirmation REMPLACER ; l'état actuel est sauvegardé juste avant.
python manage.py exporter_toutJeu complet d'exports et sauvegarde de la base.
python manage.py changepassword identifiantNouveau mot de passe pour un utilisateur (secours).
python manage.py creer_administrateurCrée un compte administrateur (secours).

Sauvegarde automatique chaque nuit (site)

PythonAnywhere, onglet Tasks, tâche quotidienne avec la commande :

COMPTABB_DATA=/home/ComptaBB/comptabb-data /home/ComptaBB/venv/bin/python /home/ComptaBB/ComptaBB/appli/manage.py sauvegarder
