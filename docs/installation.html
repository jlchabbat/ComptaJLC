ComptaJLC – Installation et mises à jour

Le site · https://comptajlc.pythonanywhere.com · octobre 2026

1. Une application en ligne

ComptaJLC est un site hébergé chez PythonAnywhere : on s'y connecte de partout (ordinateur, tablette, téléphone), par internet, avec une connexion chiffrée. Il n'y a rien à installer sur les ordinateurs. Les données sont dans comptajlc-data sur PythonAnywhere, sauvegardées automatiquement chaque nuit et à chaque mise à jour ; les exports se téléchargent depuis l'application.

2. Les modes et les mots de passe

ModeDroits
AdministrationTous les droits, dont le paramétrage de base, les imports / exports, les utilisateurs et la base de données
GestionLa tenue de la comptabilité : saisie, plan comptable, codes Anal, tiers, banque, contrôles, éditions, clôture (ni paramétrage de base, ni imports / exports, ni base de données)

Créer un compte

Administration › Utilisateurs, carte « Nouvel utilisateur » : identifiant (un nom ou une adresse e-mail), prénom, nom, e-mail, mode (Administration ou Gestion), mot de passe provisoire ; Créer l'utilisateur en haut à gauche.

Changer un mot de passe

  1. Par l'administrateur, pour quelqu'un d'autre : Administration › Utilisateurs, clic sur l'identifiant de la personne, taper le mot de passe dans « Nouveau mot de passe » (vide = inchangé), Enregistrer en haut à gauche, puis le transmettre. La même page permet de changer l'identifiant, l'e-mail, le mode, ou de bloquer l'accès (décocher « Peut se connecter »).
  2. Par chacun, pour lui-même : clic sur son nom en haut à droite (Mon compte), ancien mot de passe puis le nouveau deux fois, Changer le mot de passe en haut à gauche. On y change aussi son identifiant et son e-mail ; on peut se connecter avec l'un ou l'autre.

Conseil : l'administrateur donne un mot de passe provisoire, chacun le remplace par le sien. Un mot de passe compte au moins 8 caractères, pas uniquement des chiffres, ne ressemble pas à l'identifiant et n'est pas trop courant ; en cas de refus, le motif s'affiche sous la case.

3. Mettre à jour le site (PythonAnywhere)

1. Télécharger le code sur GitHub

  1. Ouvrir https://github.com/jlchabbat/ComptaJLC/archive/refs/heads/main.zip (ou, sur la page du dépôt, github.com/jlchabbat/ComptaJLC, bouton vert <> Code › Download ZIP).
  2. Le fichier s'appelle ComptaJLC-main.zip. Ne pas le renommer, ne pas l'ouvrir.
Prendre la branche main, sauf indication contraire : les branches ne se cumulent pas entre elles.

2. L'envoyer sur PythonAnywhere

Onglet Files, dossier /home/comptajlc/ (votre dossier personnel), Upload a file.

3. Installer, dans une console Bash

Onglet Consoles › Bash. Taper les commandes au clavier plutôt que les coller (un collage peut ajouter le texte de la ligne précédente) ; le tilde ~ s'obtient avec AltGr + 2 puis Espace, ou écrire /home/comptajlc/ à sa place.

ls ~/*.zip

Le nom doit commencer par ComptaJLC- (c'est le cas du fichier téléchargé sur GitHub). Pour vérifier la version : unzip -l ~/ComptaJLC-main.zip | head -5 doit montrer un dossier ComptaJLC-main/.

bash ~/maj.sh

Le script affiche 5 étapes : sauvegarde de la base, nouveau code, bibliothèques, base de données et paramètres, rechargement du site ; puis « MISE À JOUR TERMINÉE ». L'ancien code est gardé dans ComptaJLC-ancien, le ZIP est supprimé.

4. Vérifier

Ouvrir le site et appuyer sur Ctrl+F5. En cas de problème, remettre la version précédente du code :

bash ~/maj.sh --retour

Les données (comptajlc-data) ne sont jamais touchées par une mise à jour. La présentation et le mode d'emploi du menu Éditions sont mis à jour en même temps.

Les coches de GitHub

Dans l'onglet Actions de GitHub, chaque envoi est vérifié (tests automatiques). Une coche verte : tout est passé ; une croix rouge : un contrôle a échoué, à signaler avant d'installer. Une vérification n'ajoute ni n'enlève rien au code.

4. Sauvegarder et restaurer

Par l'application

  • Administration › Base de données : Créer une sauvegarde, Télécharger la base maintenant, Tout exporter (export complet .zip), Remettre à zéro et recharger depuis une sauvegarde, un export complet ou le classeur (taper REMPLACER).
  • Administration › Imports / Exports : Tout exporter et sauvegarder la base (un fichier par nature de données, Parametres.xlsx et une copie de la base).
  • Éditions › Exports (référentiels, écritures) : un fichier Excel par référentiel, les écritures, relevés et budget ; « Tout exporter » en .zip.

Par la console (site)

Se placer d'abord dans l'application :

cd ~/ComptaJLC/appli && source ~/venv/bin/activate && export COMPTAJLC_DATA=~/comptajlc-data
CommandeEffet
python manage.py sauvegarderSauvegarde de la base (les 3 dernières sont gardées).
python manage.py restaurerListe les sauvegardes, les plus récentes d'abord.
python manage.py restaurer 3
python manage.py restaurer derniere		Remet la base dans l'état de la sauvegarde n° 3 (ou de la plus récente), après confirmation REMPLACER ; l'état actuel est sauvegardé juste avant.
python manage.py exporter_toutJeu complet d'exports et sauvegarde de la base.
python manage.py changepassword identifiantNouveau mot de passe pour un utilisateur (secours).
python manage.py creer_administrateurCrée un compte administrateur (secours).

Sauvegarde automatique chaque nuit (site)

PythonAnywhere, onglet Tasks, tâche quotidienne avec la commande :

COMPTAJLC_DATA=/home/comptajlc/comptajlc-data /home/comptajlc/venv/bin/python /home/comptajlc/ComptaJLC/appli/manage.py sauvegarder

5. Réglages de l'association

Ce qui est propre à l'association se règle dans Administration › Paramètres (Excel) (fichier Parametres.xlsx : exporter, modifier la colonne Valeur, réimporter). Une valeur vide désactive l'option.

CléExempleEffet
nom_associationAssociation exempleNom affiché en haut des pages, sur la situation financière et les éditions.
devise€ (ou ₪, $…)Symbole des montants (écrans, Excel, messages).
releves_mizrahi(vide)Journaux dont le moyen de paiement porte un nom de banque particulier. Vide : le nom du journal est utilisé.
releve_bit(vide)Journal d'un compte de paiement mobile particulier. Vide : pas de moyen de paiement correspondant.
carte_bancaire(vide)Carte réglée par la banque le mois suivant (modèle « Paiement carte … »). Vide : pas de carte.
hebergeur_liens(vide)Site qui héberge des justificatifs gardés en lien (cadre « Joindre un lien » d'un mouvement). Vide : pas de lien.
traductions_releveouiTraduction hébreu → français des libellés du relevé (menu Banque › Traductions). Non : libellés tels quels.

Les moyens de paiement, modèles de saisie déjà créés ne changent pas quand on modifie un réglage : ils se corrigent dans Administration › Autres référentiels (avancé).

6. Installer le site (premier démarrage)

Chaque association a son propre site et ses propres données. Compter une demi-heure. L'adresse de ComptaJLC est https://comptajlc.pythonanywhere.com : elle vient de l'identifiant du compte, qui doit donc être comptajlc.

A. Le compte et l'application web (PythonAnywhere)

  1. Sur www.pythonanywhere.com : Pricing & signup › Create a Beginner account (gratuit pour essayer ; environ 5 $ par mois ensuite). L'identifiant choisi donne l'adresse du site : comptajlc → comptajlc.pythonanywhere.com. Confirmer l'adresse e-mail.
  2. Onglet Web › Add a new web app › Next › Manual configuration › Python 3.12 › Next.

B. Le programme

  1. Sur GitHub, dépôt ComptaJLC, branche main › Code › Download ZIP.
  2. PythonAnywhere, onglet Files › Upload a file : envoyer le ZIP (sans le renommer ni l'ouvrir).
  3. Onglet Consoles › Bash, puis copier cette ligne et appuyer sur Entrée :
unzip -qo ComptaJLC-*.zip -d ~/inst && bash ~/inst/*/appli/deploiement/installer.sh

Le script installe le programme et ses bibliothèques (quelques minutes), crée la base vide, écrit le fichier WSGI du site et le script de mise à jour ~/maj.sh. Il termine par INSTALLATION TERMINÉE et un code d'installation de 8 caractères : le noter.

C. Les réglages de l'application web

Onglet Web, sur la page de l'application :

RubriqueValeur (NOM = l'identifiant, soit comptajlc)
Virtualenv/home/NOM/venv
Static filesURL /static/, dossier /home/NOM/comptajlc-data/static
Force HTTPSEnabled

Puis le bouton vert Reload.

D. Le premier démarrage (dans le navigateur)

  1. Ouvrir https://comptajlc.pythonanywhere.com : la page « Bienvenue dans ComptaJLC » demande le code d'installation, puis l'identifiant et le mot de passe (12 caractères au moins) de l'administrateur.
  2. La page « Premier démarrage » décrit l'association : nom, devise, plan comptable (plan de base proposé, ou vos propres fichiers à partir des modèles vierges), premier exercice, jusqu'à trois banques, caisse, options. « Démarrer ComptaJLC » crée tout d'un coup ; tout reste modifiable ensuite (chapitre 5).
  3. Créer les utilisateurs (Administration › Utilisateurs) et importer les tiers (modèle vierge Tiers.xlsx).
  4. Sauvegarde automatique de chaque nuit : chapitre 4 (onglet Tasks), avec l'identifiant de l'association.

Pour une réinstallation (nouveau compte, données existantes) : après l'étape D.1, « Recharger une sauvegarde » (Administration › Base de données) remplace l'assistant. Un site qui a déjà des journaux ou des écritures ne voit jamais l'assistant.

E. Les mises à jour

Comme au chapitre 3 : envoyer le nouveau ZIP dans Files, puis bash ~/maj.sh. Les données de l'association ne sont jamais touchées. Tous les 3 mois avec l'offre gratuite : onglet Web › Run until 3 months from today.

F. La licence

Un site créé par l'assistant a 60 jours d'essai. Ensuite, sans licence valable, il passe en lecture seule : on consulte, on imprime et on exporte (export complet compris), on ne saisit plus.

Côté éditeur (sur votre propre compte, console du site) :

CommandeEffet
python manage.py licence clesUne seule fois : crée la clé privée dans ~/comptajlc-licence (à garder secrète et à sauvegarder hors du site) et affiche la clé publique, à inscrire dans le programme (compta/licence.py, CLE_PUBLIQUE). Tant qu'elle n'y est pas, aucune licence n'est demandée.
python manage.py licence creer --association "Association exemple" --site comptajlc.pythonanywhere.com --fin 2027-12-31Affiche la licence (texte CBB1.…) à envoyer à l'association.
python manage.py licence verifier "CBB1.…"Affiche l'association, le site et la date de fin d'une licence.

Côté association : Administration › Licence, coller le texte reçu, « Enregistrer la licence ».
