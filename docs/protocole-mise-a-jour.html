1. Quand faire une mise à jour ?

  • Chaque fois que Claude annonce qu'une modification de l'application est prête (« poussée sur GitHub » et vérification GitHub terminée).
  • Jamais pendant qu'un autre utilisateur saisit : prévenir le bureau ou les bénévoles ; la mise à jour dure environ 5 minutes.
  • Vos données (écritures, membres, fiches, relevés) sont dans le dossier comptabb-data : la mise à jour ne les efface jamais, et le script en fait une copie de sauvegarde avant tout changement.

2. Première fois seulement : installer le script de mise à jour

À faire une seule fois. Les fois suivantes, passer directement au chapitre 3.

  1. Faire les étapes A et B du chapitre 3 (télécharger le ZIP et l'envoyer dans Files).
  2. Ouvrir une console Bash (étape C du chapitre 3), puis copier-coller cette ligne et appuyer sur Entrée :
cd ~ && rm -rf maj && mkdir maj && unzip -q "$(ls -t ~/ComptaBB-*.zip | head -1)" -d maj && cp maj/*/appli/deploiement/maj.sh ~/maj.sh && rm -rf maj && echo "Script installé"
  1. Le message « Script installé » s'affiche. Continuer au chapitre 3, étape D.

3. Protocole de chaque mise à jour

ATélécharger la nouvelle version (sur votre PC)

  1. Être connecté à GitHub dans le navigateur (le dépôt est privé).
  2. Ouvrir ce lien : https://github.com/jlchabbat/ComptaBB/archive/refs/heads/claude/eloquent-feynman-x3bsmz.zip
  3. Le fichier ComptaBB-claude-eloquent-feynman-x3bsmz.zip arrive dans Téléchargements. Ne pas le décompresser. (Un nom finissant par « (2) » ou « (3) » est sans importance.)

Si la branche a été fusionnée dans main (Claude vous le dira), le lien devient : https://github.com/jlchabbat/ComptaBB/archive/refs/heads/main.zip

BEnvoyer le ZIP sur PythonAnywhere

  1. Se connecter à https://www.pythonanywhere.com (identifiant ComptaBB).
  2. Onglet Files (en haut à droite), bouton Upload a file, choisir le ZIP dans Téléchargements.
  3. Le fichier apparaît dans la liste de droite. Si un ancien ZIP ComptaBB y traîne encore, le supprimer (icône corbeille).

COuvrir une console

  1. Aller sur https://www.pythonanywhere.com/user/ComptaBB/consoles/
  2. Rubrique Your consoles : fermer toutes les anciennes consoles avec la croix ✕ (l'offre gratuite en permet 2).
  3. En haut de la page, cliquer sur Bash : une fenêtre noire s'ouvre avec ~ $.

DLancer la mise à jour

Taper (ou coller) cette commande et appuyer sur Entrée :

bash ~/maj.sh

Le script affiche 5 étapes, en 1 à 3 minutes :

MessageCe qui se passe
1/5 Sauvegarde de la baseCopie datée de la base dans comptabb-data/Exports/Sauvegardes (les 30 dernières sont gardées).
2/5 Nouveau codeDécompresse le ZIP ; l'ancienne version est gardée dans ComptaBB-ancien.
3/5 Bibliothèques PythonInstalle ce que la nouvelle version demande (peut prendre une minute).
4/5 Base de données et paramètresAdapte la base ; doit afficher « ComptaBB prêt : … mouvements dans la base ».
5/5 Rechargement du siteRedémarre le site automatiquement.
Tout va bien si la dernière ligne est : MISE À JOUR TERMINÉE. Ouvrez le site et appuyez sur Ctrl+F5.
Si le script affiche « Onglet Web > bouton vert Reload », faire ce rechargement à la main : onglet Web, bouton vert Reload comptabb.pythonanywhere.com.

EVérifier le site

Ouvrir https://comptabb.pythonanywhere.com (ou l'icône du Bureau) et appuyer sur Ctrl+F5.
Se connecter : la page s'affiche normalement, avec le menu habituel.
Tableau de bord : le nombre de mouvements et le résultat sont les mêmes qu'avant la mise à jour.
Essayer la nouveauté annoncée par Claude.
Fermer la console (croix ✕ sur la page Consoles).

4. En cas de problème

Ce que vous voyezQue faire
« Console limit reached »Page Consoles › fermer les anciennes consoles (croix ✕), puis ouvrir Bash.
« Aucun fichier ComptaBB-….zip »Le ZIP n'a pas été envoyé : refaire l'étape B, puis relancer bash ~/maj.sh.
« Ce ZIP ne contient pas ComptaBB »Mauvais fichier : rien n'a changé. Retélécharger le ZIP (étape A) et recommencer.
« No such file or directory: maj.sh »Le script n'est pas encore installé : faire le chapitre 2.
« ÉCHEC de la mise à jour »Taper bash ~/maj.sh --retour (retour à la version précédente, données intactes), puis envoyer à Claude une copie de ce qui s'est affiché.
Le site affiche « Something went wrong » ou une page d'erreur1. Taper bash ~/maj.sh --retour.
2. Onglet Web › Log files › Error log : copier les 20 dernières lignes et les envoyer à Claude.
L'ancienne présentation s'affiche encoreAppuyer sur Ctrl+F5 (ou vider le cache du navigateur).
Les chiffres ont changé sans raisonNe rien saisir. Prévenir Claude ; une sauvegarde d'avant la mise à jour existe (chapitre 5).
Ne jamais supprimer le dossier comptabb-data, ni les fichiers qu'il contient (comptabb.sqlite3 = toute la comptabilité ; secret.txt = clé de sécurité du site).

5. Sauvegardes

  • Automatiques : à chaque mise à jour, dans comptabb-data/Exports/Sauvegardes (30 dernières).
  • À faire chaque mois (et avant une clôture) : onglet Files › comptabb-data › cliquer sur comptabb.sqlite3 pour le télécharger ; le ranger sur OneDrive sous un nom daté, par exemple ComptaBB_2026-10-31.sqlite3.
  • Revenir à une sauvegarde (seulement sur conseil de Claude) : dans une console Bash, taper ls ~/comptabb-data/Exports/Sauvegardes pour voir les copies, puis cp ~/comptabb-data/Exports/Sauvegardes/NOM_DU_FICHIER ~/comptabb-data/comptabb.sqlite3 et recharger le site (onglet Web › Reload). Les saisies faites après cette sauvegarde seront perdues.

6. À ne pas oublier

  • Tous les 3 mois (offre gratuite) : onglet Web › bouton Run until 3 months from today, sinon le site s'arrête. PythonAnywhere envoie un e-mail de rappel une semaine avant.
  • Après la mise à jour, l'icône du Bureau reste valable : rien à refaire.
  • Garder ce protocole à portée de main ; Claude le mettra à jour si la procédure change.
