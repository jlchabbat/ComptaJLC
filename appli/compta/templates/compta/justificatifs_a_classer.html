1. Déposer les documents

Un fichier ZIP (dossiers compris), plusieurs fichiers PDF / images sélectionnés ensemble, ou un extrait Excel {% if hebergeur_liens %}de {{ hebergeur_liens }}{% else %}(tableau date, montant, lien){% endif %} : ses lignes qui ont un lien vers un document sont proposées au mouvement de même date et même montant ; le document reste en ligne et s'ouvre par son lien. Noms de fichiers reconnus : le n° de Mvt en tête du nom, suivi d'une espace (« 389 facture traiteur.pdf » ; seuls ces fichiers sont cochés d'office, les autres restent à classer), « Mvt 389 », « Pièce 739 » (ou pce, pc, pj), un numéro seul (n° de pièce, sinon n° de Mvt), ou une date et un montant (« 2026-03-15 facture 450,00.pdf »). Les documents restent ici tant qu'ils ne sont pas rattachés.

Message « 413 Request Entity Too Large » : le ZIP est trop gros pour être envoyé par cette page. Le couper en plusieurs ZIP de 50 Mo au plus, ou l'envoyer par PythonAnywhere › Files puis, dans une console Bash : cd ~/ComptaBB/appli && source ~/venv/bin/activate && COMPTABB_DATA=~/comptabb-data python manage.py importer_justificatifs ~/Justificatifs.zip --rattacher
